# Digital Growth Agency

Premium responsive one-page agency website built with semantic HTML, CSS, Three.js and GSAP.

## Services
- Digital Marketing
- SEO
- Social Media Marketing
- Social Media Management
- Video Editing
- Graphic Designing
- AI Graphic Designing

## Run
Open `index.html` in a browser. The 3D and motion libraries load from CDN.

## Before launch
Replace the demo email in `index.html` with the agency's real contact email. Add real social links, portfolio work and business details when available.
